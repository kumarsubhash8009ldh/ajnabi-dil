# Ajnabi Dil (अजनबी दिल) 💖

Ajnabi Dil is a real-time dating, social discovery, audio/video streaming, and chat platform built with React, WebRTC, Socket.IO, Node.js, and Capacitor for Android.

## 📱 Features
- **Live Video & Audio Streams**: Broadcast live, interact with real-time comments, and send virtual gifts.
- **1-on-1 Voice & Video Calls**: High quality WebRTC peer-to-peer audio and video calls.
- **Group Voice Rooms**: Join multi-speaker audio chat rooms with background music.
- **Direct Messaging**: Instant 1-on-1 messaging with photo/media sharing.
- **Social Feed**: Share status updates, photos, and connect with other users.
- **Virtual Shop & Economy**: Badges, VIP frames, animated gifts, and wallet coin balance.
- **Admin & Moderation Panel**: Content moderation, banned users control, and live activity tracking.

## 🛠️ Tech Stack
- **Frontend**: React, Vite, Tailwind CSS, Lucide Icons, Socket.IO Client
- **Backend**: Node.js, Express, Socket.IO, WebRTC Signaling
- **Mobile**: Capacitor (Android APK)

## 🚀 Getting Started

### 1. Backend Setup
```bash
cd backend
npm install
npm start
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

### 3. Android Build
```bash
cd frontend
npm run build
npx cap sync android
```
